# ⚡ CyberVarilla

> **Aplicación nativa Android para el control de ventas, cuentas y cobros.**

---

## ⚡ CyberVarilla  ![Android](https://img.shields.io/badge/Android-181717?style=flat&logo=android&logoColor=green)
![Kotlin](https://img.shields.io/badge/Kotlin-181717?style=flat&logo=kotlin&logoColor=yellow)

**CyberVarilla** es una aplicación **nativa para Android desarrollada íntegramente en Kotlin**, diseñada para llevar un control rápido y sencillo de **ventas, cuentas, cobros y pagos**.

La aplicación permite registrar operaciones mediante botones de importes, asociarlas a una cuenta o persona y consultar rápidamente el estado de los pagos.

También incorpora **control por voz** para facilitar el registro de operaciones.

---

## 🎯 Objetivo

CyberVarilla está pensada para quienes necesitan llevar un registro sencillo de operaciones sin utilizar sistemas de gestión complejos.

La idea es mantener todo lo necesario en una interfaz rápida:

```text
CUENTA
   ↓
IMPORTE
   ↓
REGISTRO
   ↓
PAGO
   ↓
CONTROL
```

---

# 💰 Gestión de ventas

CyberVarilla permite registrar diferentes importes utilizando botones de acceso rápido.

```text
  5        10

 15        20

 25        30

 40        50
```

Esto permite introducir cantidades rápidamente sin tener que escribir cada importe manualmente.

---

# 👤 Cuentas

Cada operación puede asociarse a una persona o cuenta.

Por ejemplo:

```text
pepe
```

La cuenta puede utilizarse como referencia para mantener organizados los registros.

---

# 💵 Control de pagos

CyberVarilla permite controlar el estado de los movimientos registrados.

La interfaz muestra un resumen de:

- **Bruto / Total**
- **Pagado**
- **N-P / No pagado**

Ejemplo:

```text
┌─────────────────────────────┐
│ BRUTO   PAGADO      N-P     │
│  15       15         0      │
└─────────────────────────────┘
```

Esto permite comprobar rápidamente el estado de las cuentas.

---

# 🎙️ Control por voz

CyberVarilla incorpora **control por voz** para facilitar determinadas operaciones.

El objetivo es poder interactuar con la aplicación mediante comandos de voz y reducir la necesidad de utilizar continuamente la pantalla.

```text
🎙️ VOZ
  │
  ▼
COMANDO
  │
  ▼
CYBERVARILLA
  │
  ▼
ACCIÓN
  │
  ▼
REGISTRO
```

---

# 💾 Gestión de registros

La aplicación dispone de acciones para administrar los registros.

### 💾 GUARDAR

Guarda el registro actual.

### 📤 EXPORTAR

Permite exportar los datos registrados.

### 🆕 NUEVO

Crea un nuevo registro.

### 🗑️ BORRAR

Elimina el registro actual.
